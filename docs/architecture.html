Insightly AWS

An AI data analyst for an online shop. Users ask questions in plain English. LangGraph agents powered by Claude write read-only SQL and charts against PostgreSQL. It runs on Amazon EKS behind layered guardrails, with metrics in Prometheus and CloudWatch.

Request flow

1 · edge

Browser → NLB → UI

Streamlit pods behind an AWS Network Load Balancer (source-IP stickiness for websockets, optional CIDR allow-list).

2 · API

UI → FastAPI /chat

Cluster-internal service. Probes: /health (liveness) and /ready (DB + agents). /metrics for Prometheus.

3 · agents

LangGraph

guard_in → router → analyst / chart / chat (tool loop) → guard_out → memory. See agentic-ai.html.

4 · data

RDS PostgreSQL

Business data queried as a read-only user inside read-only, time-limited transactions. LangGraph checkpoints in the same database.

Security layers

ThreatControls
Prompt injection (direct)Input guardrail scores the question (patterns, leetspeak, zero-width and full-width unicode, base64 payloads, 4 languages) and blocks before any LLM call
Prompt injection (indirect, via data)Tool results flagged as data; system prompt says data is never instructions; a canary token in the prompt catches leaks in answers
Data destructionSQL guard (one SELECT, keyword denylist, comments/strings stripped) → read-only transaction + timeout → read-only DB user
Personal dataPII columns blocked in SQL, redacted in results, emails/phones/keys redacted in answers
Runaway cost / loopsRecursion limit (422), max_tokens, cheap model for routing, daily cost alarm
InfrastructurePrivate RDS, TLS-only S3, non-root read-only pods, restricted Pod Security, least-privilege IAM, immutable scanned images
